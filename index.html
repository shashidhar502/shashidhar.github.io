Mobile App Deep Link Tester

Custom Schema

Uses custom URI schemes: snappauth:// (Agent • package: com.servicenow.fulfiller) and snempappauth:// (Requestor • package: com.servicenow.requestor).

Open in Edge

HTTPS Schema / App Links

Uses verified App Links via https://<instance>.service-now.com/mobileapplink?snapp=<app>. Android App Links require the instance's assetlinks.json to be configured.

Intent Schema (Android)

Uses Android intent:// URIs to target a specific package directly. Falls back to Play Store if the app is not installed (when S.browser_fallback_url is set).

Agent / Fulfiller — package: com.servicenow.fulfiller
intent://#Intent;scheme=snappauth;package=com.servicenow.fulfiller;action=android.intent.action.VIEW;category=android.intent.category.BROWSABLE;end

Requestor / Mobile — package: com.servicenow.requestor
intent://#Intent;scheme=snempappauth;package=com.servicenow.requestor;action=android.intent.action.VIEW;category=android.intent.category.BROWSABLE;end
